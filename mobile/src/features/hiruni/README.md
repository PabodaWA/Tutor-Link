# TutorLink – Booking Management

## Overview
This module contains booking management interfaces and supporting files for the TutorLink mobile application.

## Module Files
- `booking-center.tsx` – Booking management interface
- `booking-flow.tsx` – Booking flow interface
- `booking-request-types.ts` – Booking request type definitions
- `cancel-booking.tsx` – Booking cancellation interface
- `demo-booking-requests.ts` – Demo booking request data
- `reschedule-booking.tsx` – Booking rescheduling interface
- `tutor-booking-requests.tsx` – Tutor booking requests interface
- `tutor-request-details.tsx` – Tutor booking request details interface

## Development Guidelines
- Review booking-related changes before committing.
- Verify booking navigation after route changes.
- Test cancellation and rescheduling flows after modifying booking logic.
- Keep changes focused and review them before merging into the shared branch.

## Note
This documentation does not change the application's UI, runtime behaviour, or database.
